# Trail Talk JP — Strength Coach

自動カウント式の3種目補強タイマー（日本語・スマートフォン対応）。

- 親指カーフレイズ / 棒持ちランジ / 膝上げクランチ
- 左右の順番、2セット、準備3秒、休憩自動進行・スキップ
- 回数、テンポ（秒/回）、休憩時間を変更可能
- 設定は端末内にのみ保存。録画・個人情報の送信なし
- HTTPSで一度開いたあと、オフラインでも利用可能（端末のWebアプリ機能とキャッシュ条件に依存）

## GitHub Pages の設定

Settings → Pages → Build and deployment → Source: **Deploy from a branch**
→ Branch: **main** → **/(root)** → Save.

公開URLは通常 `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` です。
iPhone Safariで開いて、共有 → ホーム画面に追加 →「Webアプリとして開く」をオンにして追加してください。

**公開上の注意**: GitHub Pagesは原則として一般公開サイトです。この配布物には個人の健康情報・トレーニング動画は含みません。

このアプリは実動作を検出せず、設定秒数ごとに回数表示が進むタイマーです。
痛みやフォーム破綻があれば一時停止してください。
