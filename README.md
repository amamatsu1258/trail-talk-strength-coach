# Trail Talk Strength Coach

ランナーのための補強実施サポート・個人ログ用Webアプリ（v0.1）。

## 現在できること

- 西尾治療院で指導された3種目をベースに、**コーチ提案の初期目安**をチェックしながら実施
- 月曜「ランOFF＋低負荷補強①」、金曜「ER＋補強②」を初期表示（曜日は必要に応じて変更可能）
- 実施日、完了した種目、RPE、違和感、所感を端末内に保存
- 履歴を一覧表示・個別削除、JSON書き出し／再読み込み
- スマートフォン対応／サーバー・APIキー不要

## 公開とプライバシー

**このリポジトリはPublicです。** HTML/CSS/JavaScriptなどアプリの実装だけを公開します。
実施ログは閲覧端末のブラウザの `localStorage` にのみ保存し、GitHubやサーバーには自動送信しません。
端末変更やブラウザのデータ消去で消えるため、個人データの入ったJSONを定期的に書き出してください。書き出したJSONを公開リポジトリにコミットしないでください。

コーチング戦略、症状履歴、本人のログ、より詳細な運動データの**正本はprivateな `Trail-Talk-JP`** です。公開サイトにはそれらを埋め込みません。

## GitHub Pagesで公開する手順（初回のみ）

1. GitHubの **`amamatsu1258/trail-talk-strength-coach` → Settings → Pages** を開く。
2. `Build and deployment` の `Source` は **Deploy from a branch** を選ぶ。
3. `Branch` は **main / (root)** を選んで **Save**。
4. デプロイ完了後、**https://amamatsu1258.github.io/trail-talk-strength-coach/** を開いて動作を確認する。

> リポジトリへコードを登録しただけではPagesの初回設定は自動で有効になりません。設定後はmainへのindex.htmlの更新で公開版も再デプロイされます。公開サイトが見つからない場合はPagesの設定とデプロイ状況を確認してください。

## 運用上の注意

- メニューの回数とテンポは西尾先生の厳密な処方値ではなく、Trail Talk JPコーチの暫定目安です。
- 痛み・股関節の詰まり・代償動作が出る場合には無理に完遂しないこと。
- ランOFFと全活動休養は異なります。高負荷筋力トレーニングと軽い動作制御型の補強は別のものとして扱います。
- 競技計画や次週の補強量はprivateなTrail Talk JP正本に従って更新します。現在の公開サイトは動的にGitHubのprivate資料を読み込みません。

## 技術

単一の `index.html` にCSS/JavaScriptを含む静的Webアプリです。外部ライブラリ、アナリティクス、外部フォント、サーバーへの送信は使用しません。
